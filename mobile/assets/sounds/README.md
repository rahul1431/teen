# Game Sound Effects

Drop royalty-free `.mp3` files here (Mixkit / Pixabay / Freesound, CC0).
`SoundService` references these exact filenames and silently skips any that
are missing, so the app builds and runs before the assets are added.

Required filenames:
- button_tap.mp3
- dice_roll.mp3
- token_move.mp3
- token_capture.mp3
- token_home.mp3
- card_deal.mp3
- chip_bet.mp3
- aviator_takeoff.mp3
- aviator_tick.mp3
- aviator_cashout.mp3
- aviator_crash.mp3
- countdown.mp3
- win.mp3
- lose.mp3
- your_turn.mp3

Keep each file short (<200 KB) and normalized to roughly the same loudness.
