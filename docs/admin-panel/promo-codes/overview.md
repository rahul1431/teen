# Promo Codes — Overview

Deposit-bonus promo code management: fixed-₹ or %-based discount, min deposit requirement, max discount cap, total usage limit, per-user use limit, expiry, active toggle. Copy-to-clipboard on the code tag.

The Active toggle switch used to silently wipe the description, max discount cap, usage limit, and expiry date — a financial-risk bug (a capped/expiring promo could become uncapped and permanent) fixed 2026-07-28.
